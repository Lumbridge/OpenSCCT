# FPS benchmark results — 31 October 2026

The renderer is faster in the measured environment views. Original-game parity remains view-dependent; the tables below include both throughput and the slowest 1% of frames.

## Conditions

- Intel Core i9-14900K, GeForce RTX 4070 SUPER, Windows 11 Pro; Godot 4.7.2 .NET, Vulkan, release export.
- SteeE is Steel Squat; AquaE is Aquarium.
- Environment views: 1280×720, HUD/local pawn hidden. Natural spawn views: 1920×1080, HUD and character visible.
- VSync off, uncapped, resolution scale 1, AF 4×, no MSAA/SMAA, shadow quality 3 and smooth edges. OpenSCCT retains its previous shadow-map resolution. Both children opt out of background power throttling.
- Ten seconds measured after three seconds of warm-up per view. Runs are sequential and off screen. The final series checks that another Godot/OpenSCCT renderer is absent before and after every capture.
- Reference: installed SCCT with Reloaded, editor Play Level on its hidden desktop. This is not an unmodified retail foreground benchmark. Its verified runtime cap values are raised to 10,000; executable code and disk binaries are unchanged.
- Original throughput uses the independent Present counter; frame-time tails use native level-clock deltas. OpenSCCT uses wall-clock frame intervals. 1% low = 1,000 / mean of the slowest ceil(N×0.01) frame times.

## Changes kept

- Cache fixed map-light geometry separately from moving shadow casters, combine nearest depth, and invalidate on light movement. Skip shadow viewports whose entire influence lies outside the main camera. Preserve animated alpha masks and vision-independent shadow coverage.
- Upload light parameter textures only when values change; exclude colour-only effects from custom shadow cameras; skip colour stages in opaque depth fragments.
- Use conservative all-pose bounds for supported map skeletal props, with the old generous margin as fallback. Skip unchanged pose components and native material/visibility/audio updates.
- Cull particle draw uploads conservatively while continuing simulation. Retain rain geometry while the eye position is unchanged. Update cloth positions/normals in existing GPU buffers, retaining topology, UVs and material.
- Add opt-in camera-based benchmark capture, raw frame CSVs, screenshots, build hashes and a comparison command. Player configuration is isolated; sandbox and export overrides are restored.
- Keep the remanence compute shader as raw source in the release export, so it loads without resource errors.

The static shadow cache adds one R32F atlas (64 MiB at shadow quality 3) plus the cached viewports' attachments, trading GPU memory for less redraw work.

The default GC, render-thread model, renderer backend, mesh batching and shadow resolution are retained. Experimental managed animation-key caches, occlusion, smaller batches, worker tuning and server GC were removed. The server-GC trial produced a 90 ms worst frame in a 60-second diagnostic. Captures taken while another normal game was open after 01:04 are excluded from the final series.

- `dotnet build game/OpenScctGame.slnx -c ExportRelease`: passed, no warnings/errors.
- Final benchmark logs are checked for engine/script/shader errors. Screenshots were inspected. No test suites or smokes were run, per `CLAUDE.local.md`.
- Final release: `local/fps/verified-build/OpenSCCT.exe`. Capture folders: `verified-{SteeE,AquaE,spy-1080,merc-1080}` and matching `verified-original-*`; each holds raw CSVs, screenshots and summary data. OpenSCCT captures also hold binary/config/camera hashes in `build.json`.
- The working checkout contains unrelated concurrent edits; those were preserved. Artifact hashes identify the measured builds. These measurements cover stationary views on this machine, not every map, combat load, moving-camera case or other hardware.
- A later conservative-bounds correction widens orthographic light bounds. The measured maps use perspective map lights, so their captured paths are unaffected; the correction was build-checked.
