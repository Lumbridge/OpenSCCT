# SVMap 1.0

SVMap is the map format of SVM. Every original `.sdc` map converts to it, and native maps are authored in it. One
map is one folder:

```
<Map>/
  manifest.json            identity, provenance, per-file digests and group hashes
  sim/                     everything the server reads, in original engine conventions
    gameplay.json          actors with typed properties, tag index, event edges, mission tree, map settings
    collision.bin          collision geometry and colliders (binary, chunked)
    traversal.json         geometric events (GEs): ledges, pipes, zip lines, ladders, fences, poles, HOH bars
  render/                  client only: glTF world and mesh library (later: instances, materials, lightmaps, fx)
    world.glb
  audio/                   client only (later)
  ui/                      client only (later)
```

The dedicated server loads only `sim/`. The client loads all of it. `fixtures/testbox/` in this repository is a
complete synthetic example, generated by `python -m svmbuild.testbox`.

Schemas are JSON Schema 2020-12. Their `$id`s live under `https://svmap.invalid/1.0/`, a name that never resolves:
load them from this folder and register them by `$id`.

## `manifest.json`

`format` (`svmap`), `formatVersion`, `map` (the id, the original file stem for converted maps), `title`, `source`
(converted: original file and its sha256; synthetic or authored: generator and version), `files` (every file except
the manifest: digest and size), `hashes` (one per non-empty group: `sim`, `render`, `audio`, `ui`) and `requires`
(shared content packs). No timestamps, so a rebuild of unchanged input is byte-identical. The handshake compares the
`sim` hash and, when it differs, names the differing file from `files`.

## `sim/gameplay.json`

- `levelInfo`: the `LevelInfo` actor (`Level.Actors[0]`), with `GEActivationMask` always present.
- `actors`: every other placed actor in original level order: `id` (original export name), `class`
  (`Package.Class`), `props` and an optional `src` (`{"export": n}`, the 1-based export index in the original).
- `props` hold the values that differ from the class defaults, as the original map stores them, keyed by the
  UnrealScript property name. Values are typed:

  | UnrealScript type | JSON |
  |---|---|
  | `int`, `byte`, enum | integer (enums by value) |
  | `float` | number with a decimal point, float32 |
  | `bool` | `true` / `false` |
  | `string`, `name` | string |
  | object reference to an actor of the map | `{"$actor": "<id>"}`, `null` for None |
  | object reference to anything else | `{"$asset": "Package.Group.Name"}`, `null` for None |
  | `class<...>` | `{"$class": "Package.Class"}` |
  | struct | object keyed by member name (`{"X": 0.0, "Y": 0.0, "Z": 160.0}`) |
  | dynamic array | array |
  | static array (`ArrayDim > 1`) | `{"$elements": {"<index>": value}}` with only the stored elements |

  Converters also write the effective `Tag` of every actor and resolve `$asset` paths to full names.
- `mapSettings`: per game mode settings keyed by mode name, for example
  `{"Story": {"TimeLimit": 10, "SpiesLives": 4, "SentriesLives": 3, "RespawnTime": 10}}` (minutes, lives per player,
  seconds).
- Derived indexes, rebuilt and checked by the validator, so readers need not compute them:
  - `tagIndex`: tag -> actor ids in level order (matching ignores ASCII case, as UE2 names do);
  - `eventEdges`: `{"from", "via", "event", "to"}` for every event-name property (`Event` in 1.0) of every actor,
    `to` being the actors whose tag matches (empty when nothing listens);
  - `missionTree`: each `SMission` with `gameMode`, `minimumObjectives` and its `SObjective`s with their trigger
    actors, from the `Objectives` and `Triggers` properties.

## `sim/traversal.json`

`ges`, in original list order: `id`, `kind` (`POLE` 1, `FENCE` 2, `HOH` 4, `LG` 8, `LADDER` 16, `PIPE` 32, `ZL` 64),
`points` (2 or, for `LADDER` and `PIPE`, 3 UE-space points), `mask` (the GE ID byte: 0 always active, otherwise
active while it shares a bit with `LevelInfo.GEActivationMask`, which `SGETrigger`s toggle), `platform` (0 common,
1 PS2 only, 2 Xbox only) and `src` (original list index, authoring node, or synthetic).

## `render/world.glb`

glTF 2.0 binary in render space (see the conventions). The default scene has two root nodes: `World` (static
geometry) and `Library`, whose children are meshes named by asset path (`TestBox.Meshes.SlidingDoor`) that actors
instance through `$asset` references. The client never draws `Library` directly. Node extras carry
`{"svmap": {"role": "world" | "library" | "libraryMesh"}}`.

## Versioning

SemVer on `formatVersion`. Patch: clarifications only. Minor: new optional fields, new optional files, new
collision chunks (readers skip unknown chunks); schemas move to a new `1.<minor>` folder. Major: anything a 1.x
reader would misread.
