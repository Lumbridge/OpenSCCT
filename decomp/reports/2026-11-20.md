**PC.** Both installed files matched the sizes and content SHA-1 values in
Steam depot 13571, manifest `2604462187318687519`. The manifests additionally
lock each file with SHA-256. We compiled the named sound catalogue query with
Microsoft's x86 C compiler 19.44.35229.0 and compared its complete COFF
function section with the bytes at the exported retail address. The campaign
also covers Unreal class registration, type checks and destruction, spatial
audio mixing, streaming, and C runtime string, calendar and I/O operations.
Versus includes registered VM arithmetic and bytecode handlers, actor movement,
animation, camera selection, material composition and GUI input.
Each comparison includes the entire function,
with compiler-emitted address references resolved where required. The original
per-function compiler and flags remain under investigation. [Reproduce the comparisons](../pc/README.md).

**PS2.** The PAL disc's boot configuration identifies `SLES_532.87` as its
entry point. The two secondary ELF programs are individually fingerprinted. GCC 12.2 for MIPS reproduced all eight bytes of the accessor at EE address `0x0018b4f0` in the online program. Ghidra identified two callers, and objdiff compared the complete function.
All three mix instructions and writable data in a single file-backed
executable section. A code-range map for each program is the next step
toward a measured percentage. [Inspect the disc](../ps2/README.md).
