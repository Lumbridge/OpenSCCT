# Retail matching report · 20 November 2026

We identified five retail executables and rebuilt the first PC campaign
function from C. The candidate is a three-byte audio query. Its bytes agree with retail using a modern compiler. The original compiler and flags are still under investigation. Its small size
makes the entire compiler-to-retail comparison easy to reproduce.

| Build and program | Verified source bytes | Measured code |
| --- | ---: | ---: |
| Steam 252084 · Campaign and co-op | 0 | 8,082,506 bytes |
| Steam 252084 · Versus | 0 | 2,991,392 bytes |
| PAL 1.01 · Boot | 0 | Unmeasured |
| PAL 1.01 · Offline | 0 | Unmeasured |
| PAL 1.01 · Online | 0 | Unmeasured |

**PC.** Both installed files matched the sizes and content SHA-1 values in
Steam depot 13571, manifest `2604462187318687519`. The manifests additionally
lock each file with SHA-256. We compiled the named sound catalogue query with
Microsoft's x86 C compiler 19.44.35229.0 and compared its complete COFF
function section with the bytes at the exported retail address. Both modern MSVC /O1 and /O2 reproduced the three bytes. The Steam campaign executable records linker 7.10, and the Versus executable records linker 7.00. The compiler and flags for each function still need independent evidence. [Reproduce the candidate](../pc/README.md).

**PS2.** The PAL disc's boot configuration identifies `SLES_532.87` as its
entry point. The two secondary ELF programs are individually fingerprinted.
All three mix instructions and writable data in a single file-backed
executable section. A code-range map for each program is the next step
toward a measured percentage. [Inspect the disc](../ps2/README.md).

These measurements cover the listed executables. Assets, UnrealScript,
additional modules, other regions, campaign completion and live multiplayer
require different evidence. [Current machine-readable results](progress.json).
