# Event feed icons

Icons made by Lorc, Delapouite, Sbed, Skoll, John Colburn and Guard13007, from [Game-icons.net](https://game-icons.net/), licensed under [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/).

Source repository: [game-icons/icons at `82d948812bfe3f269ef8f731dcdb07b08160edc4`](https://github.com/game-icons/icons/tree/82d948812bfe3f269ef8f731dcdb07b08160edc4).

The black full-canvas backgrounds were removed. Most icons retain their original white paths. Shot-triggered device variants combine the specific device silhouette with the licensed Silver bullet silhouette in the upper-left corner; headshot variants combine the firearm silhouette with the licensed Headshot symbol. The choke icon turns the original Grab grip upright and adds inward compression arrows. The HUD tints the silhouettes at runtime. No generated bitmap artwork is included. [sources.json](sources.json) records upstream sources, edits and original/vendored SHA-256 hashes.
See the [HUD guide](../../../../docs/HUD.md) for the event feed implementation.

Camera gas sleep uses the three Z glyphs from Night sleep, with its crescent removed and the glyphs uniformly enlarged. Each detailed cause has its own primary icon. Proximity mines use a land-mine silhouette, laser mines a tripwire, and poison mines the biohazard symbol. Shot variants retain that same device identity and add a bullet marker. Drop attacks, falls, grabs, chokes and neck breaks have separate silhouettes. Explosive barrels, burning Molotovs, general fire and grenades are distinct. Electrical contact uses Lightning mask; taser combines a pistol and electrical bolt; charge collision combines Push with Lightning trio. These adaptations retain the original source paths with the recorded transforms. Explicit cause text accompanies every icon so meaning does not rely solely on recognition.
