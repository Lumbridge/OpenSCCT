# OpenSCCT 0.8.120 — authored and animated materials

Use with OpenSCCT Editor 0.2.34 or newer. The launcher is unchanged.

- Render imported texture sets using the shared editor/game material definition: normal and bump maps, parallax, roughness/gloss, metallic/specular, AO, opacity, emission, detail layers and supplied reflection environments.
- Play animated texture atlases and image sequences with looping, ping pong, phase, scrolling and rotation, with independent frame mipmaps.
- Load deterministic tessellated/displaced world and mesh geometry, render LODs and optional collision derived from the same final shape.
- Use directional baked world and static-mesh lighting for normal-map response, with opt-in occluded emissive illumination. Material emission does not automatically produce thermal heat or EMF activity.
- Keep stock materials on their existing rendering path and retain a basic appearance fallback in compiled content.

The matching editor includes built-in tutorials for importing texture sets, animated textures, material lighting and shine, depth/collision, emissive baking and original-game export. Open **Help → Browse Tutorials**, or search these topics with **Ctrl+Shift+P**.

Clearcoat, anisotropy, screen refraction and dominant-direction baked lighting are approximations. Original-game export reports its differences, uses the first animation frame and refuses incompatible displaced gameplay collision. See [the material contract and limits](../AUTHORED-MATERIALS.md) and the editor's compatibility guide.

Validation includes 23 authored-material GPU variants, texture import/precision checks, compiled-map loading, displaced-collision multiplayer checks for both teams and native SDC decoding/open-save-reopen/play checks. Broad low-end and stock-map acceptance remains open: supplemental stock EMF captures and shutdown checks failed on both the published 0.8.119 baseline and this feature build. These are not claimed as passing release acceptance checks.
