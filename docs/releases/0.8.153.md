Optional rifles and equipment level unlocks.

- Added an **Additional rifles** host option beside Sidearms. It defaults to off and hides the new rifles from Equipment until enabled. The setting persists across map and mode changes.
- When enabled, rifles unlock in this order: Galil at level 1, FAMAS at level 5, AK-47 at level 20 and M4A1-S at level 30.
- Mine Hack now requires level 5 and Clone requires level 10. Locked equipment is greyed out and shows its required level. The server enforces these rules, including Mercenary Deathmatch respawn choices.
- Practice, offline and unrestricted sessions retain the existing sidearm-style level bypass. Hosts must still enable the additional rifles.
- Fixed the Equipment menu's Apply loadout button falling outside an 800×600 window.

Launcher version: 0.8.63. Existing character and sound content packs remain current.
