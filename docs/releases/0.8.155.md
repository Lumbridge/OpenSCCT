Original PlayStation 2 objective support for the recovered P-suffixed Versus maps.

- Restores the green extraction vial, original animated ND133 console, and source objective materials, including the moving liquid texture.
- Supports the original vial pickup, carrying, alarm lock and return, and touch-based extraction delivery.
- Restores PS2 sabotage modem placement, one-charge refill, interrupted capture progress, mercenary removal, and shootable modem destruction with the original smoke and flash effect.
- Replicates the PS2 objective actors and state between matching clients and servers. Existing PC maps retain their current objective rules.
- Renders original materials that use an environment map without a diffuse texture.

The recovered maps are distributed separately through OpenSCCT-Content. Use this game version or newer for their original PS2 objective behavior. All players in an online session need matching game and map versions.

Launcher version: 0.8.63.
