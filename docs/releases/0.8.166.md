# OpenSCCT 0.8.166

Launcher 0.9.2 groups the PS2 and PC games under **Originals** and the Godot and Unreal versions of Spies vs. Mercenaries under **Modernisations**. OpenSCCT Editor is under **Tools**. The original PC version can use a separate Enhanced / Reloaded Versus installation.

Select your installed Steam copy of Chaos Theory to build the base content. The local converter prepares 11 stock multiplayer maps, eight tutorials, the two front-end packages, characters, audio and other shared resources. Aquarius is the default multiplayer map. Each client can reuse the completed build. An interrupted rebuild leaves the previous completed build usable.

Additional community maps are available through **Maps**. Source-based maps download the author's files and resolve their retail dependencies from your Steam installation. Existing maps and authored projects stay on disk. The original Steam game files stay in place.

The [project website](https://master.lumbridge.co.uk/) includes installation guides, site search and [original executable progress](https://master.lumbridge.co.uk/progress). Browser play has been retired. Website server links open the installed game.
